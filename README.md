# Project-2 -  Underwater Cables

You are the lead architect for a consortium of tech companies laying subsea fiber-optic cables to connect $n$ island data centers. You are given an undirected graph where each edge represents a potential cable route between two islands, and the weight of the edge is the cost of manufacturing and deploying that specific length of cable. To minimize the multi-billion-dollar budget, you must design a network that connects all $n$ data centers together using the absolute minimum total cable cost. Design an algorithm to output the optimal Minimum Spanning Tree of cable routes, ensuring no data center is left isolated. This project involves explaining MSTs, since we will not cover them in lecture.
